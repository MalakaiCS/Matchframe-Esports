## X-ray and smoke colours

There are new switches in **HUD Library → Game** when CS2 is started with HLAE (Launch mode **Observer tools + HLAE**):
- **X-ray colours:** the players' glow through walls, the names above them and grenade trails in your CT and T colours.
- **Coloured smokes:** smokes in your CT and T colours, so it's clear whose smoke is whose.
- **Colours:** **Your CT and T colours**, with two colour pickers. They start as CT blue and T red, and the colours stay with the side. Or choose **Each team's colour** (Teams → colour), which swaps with the teams at half time.

**Who sees it:** only your observer game. The players and the server see nothing different.

**When it changes:** CS2 shows the new glow from the next switch of player, and new trails and smokes from the next grenade. Turned off, the game's own colours come back the same way.

**How it works:** HLAE's `mirv_colors` commands. That's why it needs the HLAE launch mode.

## Kill feed colours

**Team colours in kill feed** is now **Colours in kill feed**. It uses the same colours as above, which by default are your CT and T colours. To keep each team's own colour, as before, set **Colours** to **Each team's colour**.
