# Matchframe Esports 0.1.2-dev — development build

**Unsigned development build. Installed and smoke-tested on a Windows CI runner; not yet used against a real CS2 client.**

## What's new: the Observer

The auto director is now the **Observer**. Choose its mode in **Live Control** and arm it with **Resume automation**:

| Mode | What it does on its own | Plans |
|---|---|---|
| **Off** | Never moves the camera. Shot suggestions stay visible. | All |
| **Observer** | Switches between player POVs. | All |
| **Observer & Cinematics** | POV observing plus cinematic static cameras: an establishing shot in freeze time, the bomb at plant and defuse, and overviews of big fights. | All |
| **Full Action Observer** | Everything above plus **nade cameras** that catch smokes, flashes, molotovs and HE grenades as they land. | Top plan (Studio) |

- **Hours:** every mode except Off uses auto-director hours on live matches, at the same rate. The simulation is free in every mode.
- **Cameras:** static shots use cameras you capture and validate in **Maps & Cameras**. Tag them by use: `establishing`, `bomb`, `tactical` (fight overviews), or `utility` (nade cameras). Like every static shot, they need a passed static camera test.
- **Plan changes:** if a plan loses Full Action Observer, the program switches to Observer & Cinematics at the next map change. It never cuts a map short.
- **Control surfaces:** Stream Deck and Companion get an `observer_mode` action.
