## New HUD: Stage

**Stage** is a new bundled HUD in the HUD Library, with a tournament-stage layout on flat royal-blue panels:
- **Top:** the series strip over the minimap on the left; the event line, score bar and players alive in the centre; the sponsor slot and killfeed on the right.
- **Bottom corners:** each team's tab and five player cards, filled with the side colour as far as the player's health.
- **Observed player:** between them, with their cam. Without a cam, the player's picture stands on a transparent backdrop, so it covers less of the game.
- **Round MVP:** at the end of a round, the key player's card grows into a tall card with the round's kills and damage. It stays into the first seconds of the next round.
- **Scoreboard:** in freeze time and timeouts, a full-width scoreboard with each team's equipment value, loss bonus and timeouts remaining.

**Settings** (the HUD's details → Settings):
- **Panel colour:** royal blue, or the dark navy of the earlier look.
- **CT and T colours.**
- **Event title and stage title** for the event line. The active match's stage name and title are used when these are empty.
- Team names in full or short; the killfeed's number of rows.
- Show or hide each part.

The lettering is Antonio, an open font bundled with the HUD with its licence.

## Icon pack

**HUD images → Icon pack** loads Counter-Strike 2's own icons on this computer for the HUDs that use them. MatchFrame doesn't include them, because they are Valve's artwork. There are three ways to load them:
- **Get CS2 icons** downloads only the icons the HUDs use, with its progress.
- **Import ZIP…** takes a ZIP of CS2's icons.
- **Import folder…** takes a folder of them.

Each icon is checked before it is kept. **Remove** goes back to MatchFrame's icons.

The Stage HUD uses your own icon set first, bundled with the HUD. It takes anything that set lacks from the icon pack, and uses MatchFrame's own icons for the rest.
