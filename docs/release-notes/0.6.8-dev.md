# Matchframe Esports 0.6.8-dev — development build

**Unsigned development build. Checked automatically on Linux and on a Windows CI runner, against stand-in CS2 consoles that behave like the one in your support file. Not yet used against a real CS2 client.**

**Coming from 0.6.7:** the program updates itself. Press **Restart now** in the status bar when the update has downloaded. Nothing to change.

## Fixed: cameras that never moved, and player switches that stopped working

Your support file (0.6.7, Mirage) showed the real cause:

- **Every camera stayed at the player.** CS2 said so each time it was asked where the camera was. The game data never showed the free camera at all.
- **The free-camera command was `spec_mode 6`.** That's CS:GO's number for the free camera; CS2's is 4 and it has no 6. Your computer had already learned CS2's first-person number earlier, but the free-camera command was never updated to match. So CS2 went into an odd view at the player, where it ignores "go to this spot" (`spec_goto`) and player selections.
- **The fallback to CS2's numbers was skipped**, because the commands no longer looked like the built-in ones.
- **After a failed camera, nothing put CS2 back in first person**, so the next automatic player switches failed too.

What 0.6.8 does:

- **One numbering for all three modes** (first person, chase, free camera). Your saved mix is corrected when the program starts: first person 2, chase 3, free camera 4.
- **Cameras find what works on your CS2:** if a camera doesn't move, it tries the other numbering's free camera, then CS2's `setpos`/`setang` (what `getpos` prints). The first one that moves the camera is kept and saved, and camera paths and moving shots use it too.
- **A camera that still doesn't move puts CS2 back in first person straight away**, and the next player switch leaves the free camera properly.
- **CS2's error answers in the director log:** if CS2 says "Unknown command" or that a command needs cheats, the support file shows it as `console reply`. It now also includes the console commands in use.
