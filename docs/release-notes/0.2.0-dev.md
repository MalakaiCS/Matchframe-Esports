# Matchframe Esports 0.2.0-dev — development build

**Unsigned development build. Installed and checked on a Windows CI runner; not yet used against a real CS2 client or a real OBS.**

## What's new: the HUD Library

Matchframe now opens into the **HUD Library**: the HUDs installed on this computer, each ready to run in three ways.

| Mode | What you get |
|---|---|
| **Transparent desktop HUD** | A separate window with only the HUD graphics over the game: transparent, always on top, click-through, never takes keyboard focus, keeps updating when the manager is minimised. Choose the monitor, position, size and scale; edit mode to drag it; remembered per HUD. |
| **Preview** | A normal window or the panel in the library, with a checkerboard to inspect transparency. |
| **OBS browser source** | **Copy OBS Browser URL**: a local address that shows only the HUD on a transparent background, at the size shown. |

- **Library:** search by name, author or tag; filter by game, category and status; grid or list; sort; Import HUD ZIP or folder; Open HUDs Folder; Run Test Data. Each card shows its thumbnail, version, status (Ready, Starting, Running, Stopped, Error) and active outputs.
- **On your computer:** imported HUDs are copied into `%APPDATA%\Matchframe Esports\huds`, keep working after the original ZIP is moved or deleted, and survive restarts. Settings are saved per HUD and apply live to every output. Duplicate, export, update (with rollback) and remove. Works offline without an account.
- **Included HUDs:** the built-in Matchframe Broadcast HUD, the **Sample CS2 HUD** (a small package to learn from) and the **Pro CS2 HUD**, adapted from Lexogrine's open-source CS2 React HUD (MIT), with a starter kit to build your own.
- **Outputs are independent:** hiding the desktop HUD doesn't touch OBS; stopping one HUD doesn't stop another. **Emergency hide** (`Ctrl+Shift+F9`) hides all HUD graphics at once; **Toggle desktop HUD** is `Ctrl+Shift+H`.
- **Tray:** Show Manager, Show/Hide HUD, Stop HUD, Quit. Quitting closes every output and stops the HUD server; nothing keeps running.
- **New layout:** sidebar with HUD Library, Teams, Players, Matches, Tournaments, Live Control, Auto Director, Replays, Cameras and Settings; a toolbar with the page, game, game-data connection and live/test data; a status bar with the local server, active HUD outputs, last data update and logs.
- **Signing in is optional:** the program opens without an account. Sign in under **Settings → Account** to use the Auto Director on live matches.

Desktop HUDs work over **Fullscreen Windowed** (borderless) games; exclusive fullscreen is not supported. In OBS, put the HUD's Browser Source above a Game Capture: the desktop HUD window isn't part of Game Capture.

Guide: [HUD Library setup and use](../operations/hud-library.md).

## Checked automatically

Package import, validation and conflicts; storage across restarts; per-HUD settings reaching desktop and OBS outputs; transparent OBS rendering; overlay window settings; updates while the manager is minimised; independent outputs; recovery when game data stops and resumes; clean quit. On the Windows runner: real-pixel transparency over another window, click-through and focus.
