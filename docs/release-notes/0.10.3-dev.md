# Matchframe Esports 0.10.3-dev — development build

**Unsigned development build. Checked automatically on Linux and on a Windows CI runner. Not yet seen on your PC.**

**Coming from 0.10.2:** the program updates itself. Press **Restart now** in the status bar when the update has downloaded.

## Vector and Lineup update now

After 0.10.1 and 0.10.2, Vector and Lineup in your HUD Library still looked like they did in 0.10.0: no series boxes, no HUD images, no new radar.

**Why:** the program updates a bundled HUD when it brings a newer version of it, and Vector and Lineup kept the version number 1.0.0 although they had changed.

**Now:**
- Both HUDs are 1.1.0.
- The program also updates a bundled HUD whenever its files changed, even if the version number didn't, so this can't happen again.

After the restart, Vector and Lineup have everything from 0.10.1, and your settings for them stay.

A bundled HUD you replaced with your own import is still left alone.
