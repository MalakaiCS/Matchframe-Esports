# Matchframe Esports 0.1.0-dev — development build

**Unsigned development build. Installed and smoke-tested on a Windows CI runner; not yet used against a real CS2 client.**

Matchframe is the **Matchframe program for Windows** (this installer: HUDs, auto director, cameras, OBS, replays, match administration) plus **the website** (payments, subscriptions, auto-director hours usage, account and team management, staff administration, and the program download).

## What you can do with it

- Install the program and rehearse a broadcast with the labelled simulation (Overview → Start labelled simulation, or `pnpm dev --sim` from source).
- Manage teams, players, events, matches, veto (with captain links), sponsors, rundown, stages/standings/brackets, HUD outputs and packages.
- Connect OBS (obs-websocket v5): program/preview, sources, audio, outputs, replay buffer capture and confirmed replay playout.
- Import CS2 demos, validate and quarantine them, apply safe raw retention, build features, train and evaluate the `contact_2s` model and run it in shadow.
- Link the program to a Matchframe account (Account & Hours) to use automatic direction on live matches with auto-director hours; HUDs, manual and advisory direction never need an account.
- Run extra operator positions from the program on other computers (File → Connection settings).

## What is not verified yet

- Real CS2 GSI ingest and real observer control (POV cuts, static cameras). Automation stays blocked until the setup tests pass on a real client.
- Windows OBS browser sources, the keyboard control adapter, and a full production on a Windows 10/11 desktop (installation and start-up pass on a Windows CI runner).
- Real Stripe payments, email delivery and a public website deployment (need the owner's accounts).
- The existing replay tool and MatchFrame service integrations (blocked: APIs not available).

## Install

Windows: download `MatchframeEsports-Setup-0.1.0.exe` from your account on the website (or the `matchframe-windows-<commit>` artifact of the **Windows program (.exe)** workflow), check its SHA-256, then run it (per-user install, choose a directory) or unzip the portable build. SmartScreen warns because the build is unsigned. From source: see README.md.
