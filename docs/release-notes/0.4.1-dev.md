# Matchframe Esports 0.4.1-dev — development build

**Unsigned development build. Installed and checked on a Windows CI runner. Not yet used against a real CS2 client.**

**Coming from 0.4.0:** the program updates itself. Press **Restart now** in the status bar when the update has downloaded. Your HUDs, settings and sign-in are kept. Everything in [0.4.0](https://github.com/MalakaiCS/Matchframe-Esports/releases/tag/v0.4.0) is included.

## Fixed

- **The game options on the Counter-Strike 2 card no longer switch each other off.** Turning on one option reset all the others to their defaults: turn on **Hide end-of-match screen**, then **Team colours in kill feed**, and the end-of-match option went off again. Each switch now changes only its own option.

## New

- **Hide CS2 kill feed** (Observer tools + HLAE): blocks CS2's own kill feed, so only your HUD's kill feed shows.
  - **Crosshair:** with **Hide game HUD** also on, the rest of CS2's HUD stays hidden and the crosshair stays visible.
  - **How it works:** HLAE's `mirv_deathmsg filter add block=1`. A rule with no player in it applies to every kill notice; I checked this in HLAE's CS2 source code.
  - **Console filters:** Matchframe clears its rule before applying the options again, so rules never stack. That also clears any kill feed filters you typed into the console yourself.

## Checked automatically

- Switching options one at a time, as the switches do, keeps the others as they were (engine test, against a stand-in CS2 console).
- The new switch sends only its own option, and appears only in the HLAE mode.
- The installed program on a Windows runner: the same checks as 0.4.0.
