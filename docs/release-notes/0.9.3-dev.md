# Matchframe Esports 0.9.3-dev — development build

**Unsigned development build. Checked automatically on Linux and on a Windows CI runner.**

**Coming from 0.9.2:** the program updates itself. Press **Restart now** in the status bar when the update has downloaded.

## Demo library settings can be changed again

**Auto Director → Demo library → Library settings** fetched the saved settings again every 10 seconds and put them back into the form. Anything you typed or picked was undone before you could press **Save configuration**.

Now what you change stays until you save it.

## Reading demos where they are

You don't need to copy demos into the ingest folder:

- **Import demos** reads demos from any folder, such as `D:\Demos`, and never moves or deletes them.
- **To have a folder of your own watched:** add it under **Ingest roots** in Library settings.
  - Matchframe deletes demos from watched folders after reading them (7 days in quarantine first).
  - To keep yours, set **Retention policy** to **Keep originals**.
- **Google Drive for desktop:** use its drive letter (usually `G:\My Drive\...`).
