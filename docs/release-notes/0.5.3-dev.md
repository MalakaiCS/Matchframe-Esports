# Matchframe Esports 0.5.3-dev — development build

**Unsigned development build. Checked automatically on Linux and on a Windows CI runner, against a stand-in CS2 and with a real OBS on Linux. Not yet used against a real CS2 client.**

**Coming from 0.5.2:** the program updates itself. Press **Restart now** in the status bar when the update has downloaded. Update the replay PC.

## The relative commands for going back and forward

The replay PC now moves through CSTV with the relative forms of `demo_gototick`, the ones you use by hand:

- **Going back:** `demo_gototick -448 relative` goes back 448 ticks (about 7 s) from where CS2 is. The replay PC uses it to stay 7 s behind the main PC (the default), and to go back for a missed kill.
- **Going forward:** `demo_gototick 448 relative` goes forward 448 ticks. With **Go back for each missed kill, then live**, the replay PC uses it after filming the kill, to go forward the same distance it went back.

0.5.2 sent the forward skip with `1` instead of `relative`. Whether CS2 really moved is still checked from the round clock each time. If it didn't move forward, the replay PC stays behind and keeps catching missed kills from there.

Step by step: [Replay PC and automatic replays](https://github.com/MalakaiCS/Matchframe-Esports/blob/v0.5.3/docs/operations/replay-pc.md).
