# Matchframe Esports 0.1.1-dev — development build

**Unsigned development build. Installed and smoke-tested on a Windows CI runner; not yet used against a real CS2 client.**

## What's new

- **Sign in to the program with your Matchframe account.** The program now opens on a sign-in screen. Use the same email and password as the website. You can also sign in with a code approved on the website.
  - If you belong to several organisations, the program asks which one this computer is for.
  - "Forgot password?" and "Create one on the website" open the website.
  - The password is sent to the website once and never stored on the computer.
- **Offline use.** After signing in, the program works offline for up to 7 days after each check. It asks to go online when that period ends.
- **Signed out on the website.** A program that is already open is never locked. Being signed out on the website (password changed or reset, account disabled, removed from the organisation, computer unlinked) shows a notice and the show keeps running. The next start asks you to sign in again.
- **Account & Hours** shows who the program is signed in as and has a **Sign out** button.
- **Pinned website.** Windows builds are pinned to the live Matchframe website: its address and licence keys are read at build time. You no longer need to enter a website address.

## Notes

- Each signed-in production computer counts towards the plan's computer limit (Free: 1). Extra operator positions that connect to the production computer (File → Connection settings) use its sign-in.
- The email address must be confirmed before signing in.
