# MatchFrame Esports 0.13.3-dev — development build

**Unsigned development build. Checked automatically on Linux and on a Windows CI runner. Not yet seen on your PC.**

**Coming from 0.13.2:** the program updates itself. Press **Restart now** in the status bar when the update has downloaded.

**On event day:** untick **Settings → General → Program → Download updates automatically**, so a newer version doesn't install if you restart the program during the show. Turn it back on afterwards.

## Four HUDs

The **Pro CS2 HUD** and the **MatchFrame Sample CS2 HUD** are no longer included. The HUD Library keeps:
- **Stage**, **Vector** and **Lineup**;
- the built-in **MatchFrame Broadcast HUD** (Classic, Minimal and Arena).

**When you update:**
- **Removed:** the first time 0.13.3 starts, the two HUDs are removed from the library.
- **Your own imports stay:** a HUD you imported yourself under the same name isn't touched.
- **Outputs:** a broadcast output that used one of them switches to the MatchFrame Broadcast HUD, so nothing on air points at a HUD that's gone.
- **Desktop HUDs and OBS sources** you had for them stop showing anything: launch or add one of the other HUDs instead.

**To keep one:** before updating, open its **⋯** menu in the HUD Library and choose **Export ZIP**. After the update, import that ZIP with **Add HUD**.

Everything else is unchanged from 0.13.2.
