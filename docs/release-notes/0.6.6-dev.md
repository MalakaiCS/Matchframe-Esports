# Matchframe Esports 0.6.6-dev — development build

**Unsigned development build. Checked automatically on Linux and on a Windows CI runner, with real FTP and FTPS servers on the test machine. Not yet used with your storage server.**

**Coming from 0.6.5:** the program updates itself. Press **Restart now** in the status bar when the update has downloaded. Nothing to change.

## Demo learning: pro demos to POV data on your storage

The Demo Library now turns pro demos into the information an observer needs, uploads it to your FTP storage, and deletes the demo. Step-by-step: [Demo learning](../operations/demo-learning.md).

- **Python set up from the program:** **Demo Library → Python for reading demos → Set up Python**. It finds Python 3.11+ on your computer and installs the packages into the program's own folder. If you don't have Python, install it from python.org first.
- **HLTV downloads as they are:** drop `.dem`, `.zip` or `.rar` files into the ingest folder. The demos are taken out of archives automatically. `.rar` needs Windows 11.
- **POV labels:** for every moment and every player, whether they get a kill, die or start a multi-frag in the next 2, 5 or 10 seconds. That is the POV a perfect observer would have been on, and what an observer model learns from.
- **Cloud storage (FTP):**
  - Each match's data (about 20–40 MB instead of a 300 MB demo) is uploaded to your server. Every file's size is checked, and a match only appears there once all of it has arrived.
  - **Encrypted (FTPS) by default:** the server's certificate is trusted at the first good connection test and checked on every connection after it. Unencrypted FTP can be chosen if the server has no FTPS.
  - The password is stored encrypted on your computer and never shown again.
  - One upload at a time, never during a live broadcast. After a failure, it tries again 10 minutes later.
- **Delete each demo once its data is uploaded:** the demo goes to quarantine once its upload is checked, and is deleted after the quarantine days (7 by default, changeable).
