# MatchFrame Esports 0.10.9-dev — development build

**Unsigned development build. Checked automatically on Linux and on a Windows CI runner. Not yet seen on your PC.**

**Coming from 0.10.8:** the program updates itself. Press **Restart now** in the status bar when the update has downloaded.

## Replays

- **No jump at the start of a break.** A break's replays could open with a flash of the last clip shown in the previous break before the new clip appeared. MatchFrame now empties the replay sources (the replay scene's, its "B" copy's, and the highlights scene's) a few seconds after the cut back to live, so an old frame can't show again.
- **Hardware decoding for replays.** The replay media sources now use OBS's **Use hardware decoding when available**, so playing a clip takes load off the processor that CS2 and the stream encoder need. MatchFrame turns it on for your replay source and its "B" copy at the next break, or when you press **Set up OBS replay scene**.
- **Support file.** It now has OBS's performance numbers (processor use, frames a second, render time, frames skipped) and each clip's size, frame rate and sound. A support file saved right after a round's replays shows where any lag comes from.
