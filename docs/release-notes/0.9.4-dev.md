# Matchframe Esports 0.9.4-dev — development build

**Unsigned development build. Checked automatically on Linux and on Windows CI runners, including the demo pipeline's tests on Windows.**

**Coming from 0.9.3:** the program updates itself. Press **Restart now** in the status bar when the update has downloaded. You don't need to set up Python again.

## Demos are read on Windows

Every demo failed with `ModuleNotFoundError: No module named 'resource'`.

The demo reader measures how much memory it used with a part of Python that only Linux and macOS have, so it stopped before reading anything on Windows. On Windows it now asks Windows for the same figure.

**After updating:** in **Auto Director → Demo library → Jobs**, press **Retry** on each failed demo.

## Checked on Windows from now on

The demo pipeline's tests now run on a Windows machine whenever its code changes. Until now they only ran on Linux, which is how this slipped through.
