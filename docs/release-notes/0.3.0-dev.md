# Matchframe Esports 0.3.0-dev — development build

**Unsigned development build. Installed and checked on a Windows CI runner; not yet used against a real CS2 client or a real OBS.**

**Coming from 0.2.0:** install this version once by hand (0.2.0 has no updater). Your HUDs, settings and sign-in are kept. From 0.3.0 on, the program updates itself.

## What's new

### Minimaps and killfeeds in every HUD

- The Matchframe Broadcast HUD (Classic, Minimal, Arena), the Pro CS2 HUD and the Sample CS2 HUD each draw a minimap and a killfeed in their own style. Included HUDs update the next time the program starts.
- Built-in radars for **Ancient, Dust II, Inferno, Mirage, Nuke, Overpass, Train and Vertigo** (Lexogrine's MIT radar drawings, with their calibration), with upper and lower levels on Nuke and Vertigo. Anubis keeps the generated outline.
- Minimap markers show flashed players and the bomb carrier, smokes are outlined in the thrower's team colour, and a planted bomb pulses.
- The killfeed shows the killer, weapon, headshot, assister and a flashed killer, and handles multi-kills. CS2's game data has no kill events, so kills are matched from the game's counters. Wallbangs, no-scopes, kills through smoke and flash assists are not in the game data and aren't shown.

### LHM-format HUDs

- HUDs made for Lexogrine HUD Manager (`hud.json`, `index.html`, `panel.json`) import with **Add HUD → Import HUD ZIP…** or **Import HUD folder…** and run as they are, without LHM or an LHM account.
- Their control panel becomes the HUD's **Appearance** settings: text, checkboxes, colours, lists, player and team pickers, and buttons that act on the running HUD.
- They get game data, Matchframe's teams, players, current match and built-in radars, and Matchframe's matched kills for their killfeed. A **TEST DATA** label shows over them during test data.
- Not supported: image inputs (such as sponsor boards), the HUD's keyboard shortcuts and player cameras. These HUDs show live data with no output delay. Fonts from Google Fonts need the internet.

### Start CS2

**Start CS2** on the Counter-Strike 2 card writes the game-data config and starts the game in the launch mode chosen in **Settings → Setup → Start CS2**:

| Mode | What it adds |
|---|---|
| **Standard** | Starts CS2 through Steam; game data only. |
| **Observer tools** | `-tools -netconport`: a connection to CS2's console (needs the free **CS2 Workshop Tools**) for the console camera control, **Hide game HUD** and **X-ray**. |
| **Observer tools + HLAE** | Starts CS2 through HLAE (a separate download): adds **No flash**, **Team colours in kill feed** and **Hide end-of-match screen**. CS2 then runs with `-insecure`: it can't join VAC-secured servers unless they set `tv_secure_bypass 1`, and using HLAE on a VAC-secured server risks a VAC ban. The program asks you to confirm first. |

### The program

- **Automatic updates:** updates download in the background and install when you quit, or straight away with **Restart now** in the status bar. The program never restarts on its own. **Settings → General → Program** has Check for updates, What's new and Download updates automatically.
- **Own title bar:** the header is the title bar, with the window buttons in the program's colours.
- **HUD Library:** switches for Test data, Show HUD graphics and Utility on the radar, a Counter-Strike 2 card, an **Add HUD** menu, and HUDs grouped by category.

Guide: [HUD Library setup and use](https://github.com/MalakaiCS/Matchframe-Esports/blob/v0.3.0/docs/operations/hud-library.md).

## Checked automatically

This release is published only after these pass on the installed program on a Windows runner:

- The installed program opens into the HUD Library with the included HUDs and signs in against a local website.
- The built-in radar images are served.
- The transparent desktop HUD (`scripts/overlay-check.cjs`):
  - Window settings and transparent pixels.
  - Over a stand-in game window: real screen pixels, click-through and keyboard focus.
  - Edit mode, scale and position.
  - Live settings, and updates while the manager is minimised.
  - The OBS output, independent outputs and the emergency-hide hotkey.
  - Recovery after an engine restart, Stop, and a clean quit.
- The update files (`latest.yml` and the installer's `.blockmap`).

Unit and end-to-end tests cover:

- Kill matching and the built-in radars.
- Start CS2's launch plans and console lines, against a stand-in CS2 console.
- LHM-format HUD import, settings, buttons and data access.

The LHM support was also checked in a browser with a real LHM-format CS2 HUD: its scorebug, minimap, players, killfeed, fonts and panel button.
