# MatchFrame Esports 0.13.0-dev — development build

**Unsigned development build. Checked automatically on Linux and on a Windows CI runner. Not yet seen on your PC.**

**Coming from 0.12.4:** the program updates itself. Press **Restart now** in the status bar when the update has downloaded.

**Changes you'll notice straight away:**
- **Slow motion** around each kill is on by default in automatic replays. Turn it off in Automatic replays → Slow motion.
- **Stage HUD:** the full-width scoreboard now shows only in timeouts and tech or match pauses.

## Map intros

**Replays & Production → Map intros:** one video per map (Ancient, Anubis, Dust II, Inferno, Mirage, Nuke, Overpass, Train, Vertigo, Cache), plus a default for maps without one.

**Start the intro** at one of these moments:
- Manual only;
- When the map loads;
- Knife round start;
- Pistol round start (the default);
- Both pistol rounds;
- When the match goes live.

**How it plays:**
- **Once per map:** each map's intro plays once per map per match, and only in warmup or freeze time.
- **Round goes live:** if the round goes live during the intro, it cuts back to the game, unless you choose **Finish the intro**.
- **Where it plays:** MatchFrame makes a "MatchFrame Map Intro" scene in OBS and uses your MatchFrame Stinger if you have one. vMix works too.

**Controls:**
- **Live Control:** Play map intro, Play next map's intro and Stop.
- **Hotkey:** Ctrl+Shift+F4 in the program, plus a global hotkey (off until set).
- **Stream Deck:** `map_intro_play` and `map_intro_next`.

Knife rounds are recognised as round 1 at 0–0 with knives only. That needs the observer's game data. See `docs/operations/map-intros.md`.

## Replays

**Slow motion:**
- **Modes:** Kill moment (the default), Whole clip or Off, at 50% or 33% speed.
- **Game sound:** goes quiet during the slowed part. You can choose slowed sound instead.
- **Timing:** replays still finish by 1:50.
- **Smooth slow motion** is optional. It is used only when the file will still be ready in time.
- **Per clip:** a **Slow** button on each clip, and a `replay_slow` Stream Deck action.

**Multi-angle replays (experimental):**
- **Turning it on:** on the replay PC, tick **Film extra angles**. Until then, nothing changes.
- **What it films:** after a kill, the replay PC goes back and films it again from the victim's view or a still camera. That angle plays straight after the killer's view, slowed.
- **Which kills:** the round's top kill, plus any kill you star (☆, or the `replay_star` Stream Deck action).
- **Not yet tested** against a real CS2 server.

## Auto Director

**Clutches:**
- In a 1vX, the camera stays on the clutcher.
- It takes short looks (2–4 s) at a hunter who is closing in, entering the clutcher's site, or planting or defusing.
- It cuts back to the clutcher before the fight starts, and never flicks back and forth.

**Freeze time tells the buy story:**
- each team's buy is read: pistol, eco, force, half, full or anti-eco;
- on a force buy, the forcing team gets a closer shot;
- on an eco against a full buy, both teams are shown, the full buy last.

There's also a new "Buy type" cue that HUDs can use. No HUD draws it yet.

## Low-spec mode

**Settings → General → Performance → Low-spec mode (one PC),** for when CS2, OBS and MatchFrame run on one PC:
- HUDs capped at 30 fps, without heavy effects;
- OBS browser sources made by MatchFrame set to 30 fps;
- the engine's memory capped;
- background jobs waiting during live rounds;
- no smooth slow motion.

The program suggests it once if your HUD stutters while CS2 runs on the same PC.

## Updates and data safety

**Settings → General → Program:**
- **Update channel:** Stable or Beta.
- **Go back to a previous version:** lists earlier versions, checks the download, and restores the copy of your data that version can read.
  - It refuses if there isn't one.
  - Only versions from 0.13.0 on can be gone back to safely this way.

Before each update the program keeps a copy of your database, named with the version it came from. A version opening data saved by a newer version now refuses instead of damaging it.

## Crash reports (off unless you turn them on)

**Settings → General → Program → Send crash reports.**
- **What's sent:** the support file (passwords, keys and tokens removed) and the error.
- **Where it goes:** to MatchFrame support.
- **Confirmation:** you get an ID like CR-XXXX-XXXX to quote.
- **Asking:** if a crash happens while it's off, the next start asks once.

**For the website:** crash reports need the website's API updated to this version (it adds database migration 7). Until it is, reports wait on the computer and are sent later.

## Code signing

The build signs the installer and program as soon as the Azure Artifact Signing details are added to GitHub. See `docs/operations/code-signing.md`. This build is still unsigned.

## Stage HUD

- **Player cards:** always show the main gun, whatever the player is holding.
- **Names:** shrink to fit instead of being cut off.
- **Line-up:** cards, health numbers and scores are lined up, and the round-kill diamonds sit on the card's top edge.
- **Pause scoreboard:** only in timeouts and tech or match pauses, with every column in a box.
- **A pause** shows the PC mark on the score bar.
- **Trophy:** upload one in **HUD images → Marks → Trophy** and it shows in the middle of the tournament bar.
- **Killfeed:** stays in its place whether or not a sponsor is showing.
- **Team without a logo:** shows its short name in the logo tile.
