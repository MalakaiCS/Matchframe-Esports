# MatchFrame Esports 0.13.2-dev — development build

**Unsigned development build. Checked automatically on Linux and on a Windows CI runner. Not yet seen on your PC.**

**Coming from 0.13.1:** the program updates itself. Press **Restart now** in the status bar when the update has downloaded.

**On event day:** untick **Settings → General → Program → Download updates automatically**, so a newer version doesn't install if you restart the program during the show. Turn it back on afterwards.

## Seven languages

**Settings → General → Language:**
- **Choices:** System (Windows' display language, else English), English, Português (Brasil), Español, Deutsch, Français, Polski or Русский.
- **Applies at once,** without a restart, in the console, the tray menu, the program's windows, dialogs and notifications.
- **Machine-translated:** the setting says so. Report anything that reads wrong to support.

**What's translated:** every screen of the program, including Live Control, Automatic replays, Replays & Production, Map intros, Team Comms, the HUD Library, Teams, Players, Matches and Settings. Numbers, times and money use each language's style (German shows "0,5 s").

**Stays English on purpose:**
- the HUDs' on-air text (ROUND, TIMEOUT) and a HUD's own settings labels;
- the match graphics drawn for the broadcast (thumbnails, stingers, reel cards);
- CS2's gun names and OBS's transition names;
- messages written by the engine (for example "The Auto Director is off.");
- the website and the docs.

**Long text:** German and Russian were checked at 1600×980 and 1280×720 with nothing cut off. On narrower windows, the top bar drops a few small labels in the longer languages.

## HLAE set up and kept up to date for you

**Settings → Setup → Start CS2**, with the HLAE mode selected:
- **Get HLAE:** downloads the latest HLAE from its official releases on GitHub, checks the file against GitHub's checksum, unpacks it into the program's data folder and uses it. CS2 must be closed.
- **Keep HLAE up to date** (on): the program looks for a newer HLAE when it starts and before **Start CS2**, at most every 30 minutes. Never while CS2 is running, so never during a match. The version before stays on the computer.
- **When a CS2 update breaks HLAE:** if HLAE fails to start CS2, the program looks for a newer HLAE straight away, installs it and starts CS2 once more. If none is out yet, it says so: HLAE can take a few days to catch up with a CS2 update, and the Standard mode works until then.
- **Check for a newer HLAE** asks now. The download's progress shows while it runs.
- **Choose HLAE.exe…** still uses an HLAE you installed yourself; the program doesn't update that one. **Get HLAE** switches to the program's own.
- **Windows Security** sometimes flags HLAE's injector. If it removes a file, the program names it: allow it in Windows Security, then press **Get HLAE** again.

**Not yet tried** against GitHub's real HLAE releases from a PC: press **Get HLAE** once and start CS2 with it before relying on it at an event. If HLAE's release can't be checked, **Get HLAE** refuses and says to choose an HLAE.exe instead.

HLAE is made by the advancedfx team (MIT licence) and is not in MatchFrame's installer: the program fetches it from HLAE's own releases.
