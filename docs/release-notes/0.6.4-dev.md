# Matchframe Esports 0.6.4-dev — development build

**Unsigned development build. Checked automatically on Linux and on a Windows CI runner, against a stand-in CS2 console. Not yet used against a real CS2 client.**

**Coming from 0.6.3:** the program updates itself. Press **Restart now** in the status bar when the update has downloaded. Nothing to change.

## No X-ray in clutches

When one player is left alive against two or more, X-ray goes off until the round is over, so viewers don't see the other team coming and a won clutch looks the way it felt. X-ray comes back on for the next round.

- On by default whenever X-ray is on: **HUD Library → Game options → No X-ray in clutches**.
- Only in the console launch modes (Observer tools, with or without HLAE), like the other game options.

## Names above the players with X-ray

With X-ray on, Matchframe now also sends `hud_showtargetid 1`, so each player's name shows above them and viewers can tell who is who without the minimap. The names go off with X-ray, clutches included.

## Fixed: player numbers one too low

CS2 counts its observer slots from 0, while the number keys and broadcasts count from 1 (1–9, then 0 for the tenth player). Matchframe passed CS2's slot straight on, so kaiHUD's minimap showed the first player as 0, the second as 1, and so on.

- Every player now carries their number key, and HUDs get that number, kaiHUD included.
- kaiHUD also uses these numbers to decide which team goes on the left, so that is now right too.
- Live Control's number keys and the Stream Deck labels use the same numbers.

## Coaches hidden

A coach listed with a team (CS2 lists them as a sixth player) is no longer shown on scoreboards, the minimap, the team columns or in the HUD data, and the director never picks one.

- **Found automatically:** a name with "coach" in it, or, on a team listing more than five, the one with no observer slot, or the one not alive in freeze time while the other five are.
- **Set in the roster:** a player whose roster role is Coach.
- **Set by hand in Live Control:** a team showing more than five players asks which one is the coach. A coach shows under their team as *Coach: name* with **Not a coach** to undo it. The choice is kept for that player.
- A coach gets no number key, and the players are numbered round them.
