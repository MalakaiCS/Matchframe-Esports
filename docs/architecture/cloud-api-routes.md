# Matchframe cloud API — route reference

Generated by `pnpm cloud:openapi` from `services/cloud-api`. Website routes use the `mf_session` cookie (HttpOnly, SameSite=Lax) and refuse cross-origin browser mutations; desktop routes (`/v1/device/*`) use `Authorization: Bearer <device token>`. Request bodies are validated against `packages/cloud-contracts`. Full schemas: `cloud-openapi.json`.

| Method | Path | Purpose |
|---|---|---|
| GET | `/v1/health` | Health |
| GET | `/v1/downloads` | Matchframe program for Windows (.exe installer): URL, version, SHA-256 |
| GET | `/v1/site` | Business details shown on the website (company name, support email, legal effective date) |
| POST | `/v1/contact` | Contact form: stored for the staff support inbox (and emailed to MF_SUPPORT_EMAIL when set) |
| POST | `/v1/auth/signup` | Create an account and organisation (signs in; sends a verification email) |
| POST | `/v1/auth/login` | Sign in |
| POST | `/v1/auth/logout` | Sign out this browser |
| GET | `/v1/auth/me` | Current user and organisations |
| PATCH | `/v1/auth/me` | Change your display name |
| POST | `/v1/auth/change-email` | Change your email address (confirmed from a link sent to the new address) |
| POST | `/v1/auth/confirm-email-change` | Confirm a new email address from the emailed link |
| POST | `/v1/auth/verify-email` | Confirm an email address from the emailed link |
| POST | `/v1/auth/resend-verification` | Send the verification email again |
| POST | `/v1/auth/request-password-reset` | Email a password reset link (always answers OK) |
| POST | `/v1/auth/reset-password` | Set a new password from a reset link (signs out other sessions) |
| POST | `/v1/auth/change-password` | Change password (signs out other sessions) |
| GET | `/v1/auth/sessions` | Browsers signed in to your account |
| DELETE | `/v1/auth/sessions/:id` | Sign out one browser |
| POST | `/v1/auth/sessions/revoke-others` | Sign out every other browser |
| GET | `/v1/auth/export` | Download a copy of your account data (JSON) |
| POST | `/v1/orgs` | Create another organisation (you become its owner) |
| GET | `/v1/orgs/:orgId` | Organisation details |
| PATCH | `/v1/orgs/:orgId` | Rename the organisation |
| GET | `/v1/orgs/:orgId/members` | Members and pending invites |
| POST | `/v1/orgs/:orgId/invites` | Invite someone by email |
| DELETE | `/v1/orgs/:orgId/invites/:inviteId` | Withdraw a pending invite |
| GET | `/v1/invites/:token` | Preview an invitation |
| POST | `/v1/invites/:token/accept` | Accept an invitation (the signed-in email must match) |
| PATCH | `/v1/orgs/:orgId/members/:userId` | Change a member's role |
| DELETE | `/v1/orgs/:orgId/members/:userId` | Remove a member (or leave, when it is you) |
| GET | `/v1/plans` | Public plans and hour packs |
| GET | `/v1/orgs/:orgId/billing` | Plan, subscription, auto-director allowance, credits and invoices |
| POST | `/v1/orgs/:orgId/billing/checkout` | Start Stripe Checkout for a plan or an hour pack |
| POST | `/v1/orgs/:orgId/billing/portal` | Open the Stripe customer portal (change plan, payment method, cancel) |
| POST | `/v1/stripe/webhook` | Stripe webhook endpoint (signature-verified) |
| POST | `/v1/device/authorize` | Desktop: start linking; shows the user code to enter on the website |
| POST | `/v1/device/token` | Desktop: poll until the user approves; returns the device credential once |
| POST | `/v1/device/entitlement` | Desktop: fetch a signed entitlement (plan, features, auto-director allowance) |
| POST | `/v1/device/usage` | Desktop: upload auto-director usage records (idempotent) |
| POST | `/v1/device/unlink` | Desktop: unlink this computer |
| GET | `/v1/keys` | Public keys for verifying entitlements (Ed25519, SPKI PEM by key id) |
| GET | `/v1/device-link/:userCode` | Preview a pending link request before approving it |
| POST | `/v1/device-link/approve` | Approve a computer for an organisation |
| POST | `/v1/device-link/deny` | Refuse a link request |
| GET | `/v1/orgs/:orgId/devices` | Linked computers |
| DELETE | `/v1/orgs/:orgId/devices/:deviceId` | Unlink a computer (its credential stops working; cached entitlements expire on schedule) |
| GET | `/v1/orgs/:orgId/usage` | Auto-director usage: period totals, daily and per-computer breakdown, recent sessions |
| GET | `/v1/admin/overview` | Staff: headline numbers (accounts, organisations, computers, usage, revenue) and recent sign-ups |
| GET | `/v1/admin/users` | Staff: search accounts (q = email, name or id; filter = all \| unverified \| staff \| disabled) |
| GET | `/v1/admin/users/:userId` | Staff: one account with organisations, signed-in browsers and recent activity |
| POST | `/v1/admin/users/:userId/verify-email` | Staff: mark an account's email address as verified |
| POST | `/v1/admin/users/:userId/resend-verification` | Staff: send an account's verification email again |
| POST | `/v1/admin/users/:userId/password-reset` | Staff: email a password reset link to an account |
| POST | `/v1/admin/users/:userId/sign-out` | Staff: sign an account out of every browser |
| PUT | `/v1/admin/users/:userId/staff-role` | Admin: set an account's staff role (support, admin or none) |
| POST | `/v1/admin/users/:userId/disable` | Admin: disable an account (signs it out; it cannot sign in until enabled) |
| POST | `/v1/admin/users/:userId/enable` | Admin: enable a disabled account |
| PATCH | `/v1/admin/users/:userId` | Admin: edit an account's name or email (a new email must be verified again) |
| GET | `/v1/admin/orgs` | Staff: organisations with plan, status, members, computers and this period's usage |
| GET | `/v1/admin/orgs/:orgId` | Staff: one organisation with subscription, allowance, members, computers and hour credits |
| POST | `/v1/admin/orgs/:orgId/credits` | Admin: grant auto-director hours (support credit, trial extension) |
| GET | `/v1/admin/catalog` | Staff: full plan and hour-pack catalogue including Stripe price ids |
| PUT | `/v1/admin/plans/:planId` | Admin: create or edit a plan |
| PUT | `/v1/admin/hour-packs/:packId` | Admin: create or edit an hour pack |
| GET | `/v1/admin/audit` | Staff: recent audit events (optionally for one organisation) |
| GET | `/v1/admin/stripe-events` | Admin: recent Stripe webhook events and processing errors |
| GET | `/v1/admin/messages` | Staff: contact form messages (status = open \| handled \| all) |
| POST | `/v1/admin/messages/:messageId/handled` | Staff: mark a contact message handled (or reopen it) |
| GET | `/v1/admin/emails` | Staff: recent emails sent by the website (recipient, subject, delivery state; no bodies) |
| POST | `/v1/admin/emails/:emailId/resend` | Admin: send an email again (after an SMTP outage) |
| GET | `/v1/openapi.json` | OpenAPI description of this API |
