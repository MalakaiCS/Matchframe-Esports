# Matchframe local API — route reference

Generated from the engine's router (`Router.routeList()`); regenerate when routes change. All routes except `public` require a bearer token (`Authorization: Bearer <token>`, `x-matchframe-token`, `mf_token` cookie, or `?token=`) whose role grants the listed permission. Mutations are rejected for foreign browser origins. Request bodies are JSON validated with zod schemas defined next to each route in `services/local-engine/src/routes/*.ts`.

## WebSockets

- Operator: `ws://127.0.0.1:37211/api/v1/ws?token=…` (permission `state.read`). Messages are `EventEnvelope` objects (`packages/contracts/src/envelope.ts`) with topics `state.snapshot` (operator snapshot: state, director decision, top candidates, opportunities, mode, controls, ownership, pending command, current shot, capabilities, program, OBS, simulated flag, metrics, device tally — see `operatorSnapshot()` in `services/local-engine/src/servers.ts`), `director.decision`, `observer.command` (arbiter events), `alerts`, `capabilities`, `events` (derived match events). Clients may send `{"type":"ping"}`; all commands go through REST.
- Overlay (read-only): `ws://127.0.0.1:37212/overlay-ws?output=<id>&variant=<v>&t=<output token>`. Receives `{topic:"hud.snapshot", sequence, sentAt, payload: HudState}` (`packages/hud-sdk/src/state.ts`). The only accepted inbound message is a sponsor display acknowledgement `{type:"ack", sponsorId, zone, shownAt, durationMs}`.

## Overlay HTTP

- `GET /overlay/:outputId/:variant?t=<token>` — browser-source page for a published output (built-in HUD served directly; imported packages redirected to `/huds/<id>/<entry>`).
- `GET /overlay-api/radar/:map` — schematic radar outline (cells/polygons in normalized u,v).
- `GET /assets/:assetId`, `/hud/*` (built-in renderer assets), `/sdk/*` (HUD SDK bundle for imported packages).
