# Pro CS2 HUD (source)

Source of the `matchframe.pro-cs2` HUD package that ships with Matchframe Esports. `pnpm --filter @matchframe/hud-template build` writes the installable package to `dist/`; the program installs it into the HUD Library on first start. See [package-files/README.md](package-files/README.md) for what it shows, how to build your own HUD from it, and the licences.
