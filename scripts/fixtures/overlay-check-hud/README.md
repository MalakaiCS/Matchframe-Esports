# Overlay check HUD (test fixture)

The HUD that `scripts/overlay-check.cjs` imports into the installed program to check the desktop HUD
window (click-through, focus, settings reaching the HUD live, the OBS browser-source output). It is the
former MatchFrame Sample CS2 HUD, kept here only as a test fixture: the program doesn't ship it (ADR-085).
