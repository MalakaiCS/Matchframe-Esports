# Feature coverage F01–F35

One row per capability and its main subfeatures. Status vocabulary (spec §2): **planned**, **implemented**, **simulated**, **tested with fixtures**, **tested with real integration**, **blocked**, **intentionally excluded** (recorded scope decision). A feature is never marked complete because a screen exists. Acceptance scenario status: docs/acceptance.md.

Environment for every "tested" entry: Ubuntu 24.04.5 container, Node 22.22.0, Python 3.13.17, Chromium (Playwright), OBS 30.0.2 headless, five public 2023 CS2 demos. Not available: CS2 client, Windows, replay tool, MatchFrame service, Stream Deck/Companion, camera hardware.
